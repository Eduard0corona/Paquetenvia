# AZR-001 operations contract family

This directory preserves the authoritative recovered source artifacts for the AZR-001 v0.8 contract family and records later operational state without rewriting history.

## Preserved source artifacts

The following files are historical source records. Their content is preserved as supplied, including governance fields that were accurate at the time each artifact was produced:

- `azr-001-v0.8.md` — frozen AZR-001 v0.8 contract and AC-001 through AC-066 catalog.
- `e-001-v0.3.md` — E-001 v0.3 normative erratum.
- `azr-001-dec-001.md` — canonical recovered Owner decision record for AZR-001-DEC-001.
- `e-002-v0.13.1.md` — recovered E-002 v0.13.1 pre-approval artifact.

Do not update those files merely to reflect a later approval or authorization. In particular, the pending decision recorded by AZR-001 v0.8 and the pre-approval fields in E-002 v0.13.1 remain part of the historical record.

## Current state

[`current-state.md`](current-state.md) is the separate, time-bounded record of later approvals, authorization, validation, and environment status. It does not amend the text of a preserved source artifact.

[`source-recovery-status.md`](source-recovery-status.md) records the provenance and SHA-256 verification used to materialize this directory.

The legacy untracked file at `docs/operations/azr-001-dev-synthetic-v0.8.md` is not part of this contract family and is not normative authority.
