# 1. Propósito y frontera

AZR-001 crea el primer ambiente Azure reproducible de Paquetenvía para desarrollo, integración, demostración y validación remota exclusivamente con datos sintéticos.

Debe permitir:

- desplegar un objeto Git exacto certificado por Foundation CI;
- ejecutar Web, API y Worker;
- utilizar PostgreSQL/PostGIS administrado;
- validar RLS real;
- validar SignalR/WebSockets;
- ejecutar seed sintético sin saltarse contratos funcionales;
- validar Operations Dashboard, Tracking y PWA;
- validar RTE-001 mediante `RouteChanged + REST refetch`;
- demostrar procesamiento Worker/outbox;
- correlacionar código → CI → imagen → revision;
- diagnosticar;
- resetear;
- hacer rollback;
- destruir explícitamente el entorno;
- observar costo.

No autoriza:
